# YouTube sources

Canonical import list used while building the Mauritian Creole dataset. URLs are `watch?v=` only (no `pp`, `t`, or other query params).

Audio is **not** shipped in this repository. You must have the rights to download and annotate any source before ingesting it. Treat this list as a research catalog, not as redistributable media.
